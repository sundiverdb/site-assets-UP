# Screen reader cheat sheets

Quick references for the six screen readers I use most when testing websites. Each one covers where to get the screen reader, how to set it up for testing, and the keys or gestures I use most on the web.

| Screen reader | Platform | PDF |
| --- | --- | --- |
| JAWS | Windows | [JAWS cheat sheet](JAWS-Cheat-Sheet.pdf) |
| NVDA | Windows | [NVDA cheat sheet](NVDA-Cheat-Sheet.pdf) |
| Narrator | Windows | [Narrator cheat sheet](Narrator-Cheat-Sheet.pdf) |
| VoiceOver | Mac | [VoiceOver for Mac cheat sheet](VoiceOver-Mac-Cheat-Sheet.pdf) |
| VoiceOver | iPhone and iPad | [VoiceOver for iPhone and iPad cheat sheet](VoiceOver-iPhone-iPad-Cheat-Sheet.pdf) |
| TalkBack | Android | [TalkBack for Android cheat sheet](TalkBack-Android-Cheat-Sheet.pdf) |

The PDFs are tagged for accessibility (PDF/UA), with real headings, table headers, a document title and the language set, so they work with the screen readers they describe.

All six are also on one web page: [Screen Reader Cheat Sheets](https://www.usablepatterns.net/2026/11/13/screen-reader-cheat-sheets/). That page also explains how to test the Windows screen readers on a Mac for free.

Last checked November 2026. Screen readers change with every release. If a command has changed or I have one wrong, please [open an issue](https://github.com/sundiverdb/site-assets-UP/issues).
